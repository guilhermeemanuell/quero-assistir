PREFERÊNCIAS E SINCRONIZAÇÃO

Configurações

Sincronização privada pelo GitHub

Use um repositório privado separado para guardar sua biblioteca. O token fica salvo somente neste dispositivo.

Crie um Fine-grained personal access token limitado ao repositório privado, com permissão Contents: Read and write. Não coloque o token nos arquivos do site.

Busca automática de títulos

TMDB localiza filmes, séries e pôsteres. Ao selecionar um resultado, OMDb consulta a nota IMDb uma única vez; a nota e o identificador são salvos no título.

As chaves ficam salvas neste dispositivo e são copiadas para o repositório privado quando você sincroniza. O token do GitHub continua exclusivo de cada dispositivo. Sem as chaves, você ainda pode cadastrar títulos manualmente.
